# gallant-input

Programmatic signal analysis

## Directory Stucture

* `data`: Placeholder directory for local, temporary data files.  (Add permanent files to `test/test_input`.)
* `devops`: Integration and automation of software development: Docker, scripts, files, etc.
* `gallant_input`: Python package defining production code.
* `lib`: Necessary libraries.
* `rxtx`: Python package defining static receivers/transmitters.
* `test`: Python package defining unit, component, and system test cases.
